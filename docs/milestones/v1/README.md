# 1.0.0 시대의 마일스톤

완료된 마일스톤의 실측 기록이 여기 쌓인다. 완료 시점에 옮기고 그 뒤로는 **동결**한다 —
링크 수정 말고는 편집하지 않는다. 계획 자체는 [`PLAN.md`](../../../PLAN.md) 에 있다.

번호는 **M1 부터 다시 시작한다.** 0.1.1 까지의 M0 ~ M17 은
[`docs/archived/v0.1.0-v0.1.1/`](../../archived/v0.1.0-v0.1.1/) 에 있다. 같은 번호가 두 시대에
존재하므로 경로로 구분한다 — 아카이브의 M1 은 매니페스트, 여기의 M1 은 라이브 발행이다.

커밋 메시지와 PLAN.md 안에서 아무 수식 없는 `M1` 은 **이 시대**를 뜻한다. 옛것을 가리킬 때는
경로를 함께 적는다.

| | | |
|---|---|---|
| M1 | [라이브 발행 1회](m01-live-publish.md) | `hawakiki/luau-mathlib@0.1.0` 발행. Rarn·Wally 양쪽에서 설치 확인 |
| M2 | [별칭 충돌 정책](m02-alias-scope.md) | 섹션 단위로 확정. 전역으로 세던 것이 링커의 문서화된 동작을 막고 있었다 |
| M3 | [파이프라인 `cli/` 탈출](m03-install-pipeline.md) | `src/install/run.ts`. 합성 테스트 8개, 행동 변화 0 |
| M4a | [스키마 리뷰](m04a-schema-review.md) | 안건 4개 결론. 읽다가 파싱 안 되는 Luau 를 내던 결함 발견 |
